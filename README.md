# Cogwheel's List

Cogwheel's List is a macOS sync relay between Apple Contacts and a specified Google Sheet. It keeps both sources synchronized bidirectionally.

The app does not provide its own data-editing UI. Users edit contacts in Apple Contacts or rows in the selected Google Sheet; Cogwheel's List handles synchronization and conflict behavior.

## Repository layout

- `10_specs/platform_support/` contains the numbered platform-support specifications.
- The top-level documents define architecture, contribution, governance, installation, security, support, and release policy.
